================================================
  인체 해부학 3D 뷰어 (약대·의대 학습용)
  Windows 사용 방법
================================================

★ 가장 쉬운 방법 ★
1. 압축을 풉니다.
2. "실행하기.bat" 파일을 더블클릭합니다.
3. 브라우저가 자동으로 열리고 3D 뷰어가 실행됩니다.
4. 종료할 때는 검은 창(명령 프롬프트)을 닫으면 됩니다.

※ Python이 필요하다면
   - Microsoft Store에서 "Python" 검색 후 설치
   - 또는 https://www.python.org 에서 설치
     (설치할 때 "Add Python to PATH" 를 꼭 체크)

------------------------------------------------
모델이 "로드 실패" 라고 나올 때
------------------------------------------------
브라우저에서 index.html을 직접 더블클릭하면
보안 정책 때문에 모델 파일이 차단됩니다.
반드시 "실행하기.bat" 으로 실행하세요.

------------------------------------------------
조작법
------------------------------------------------
- 왼쪽 목록에서 장기 클릭
- 마우스 왼쪽 드래그 : 회전
- 마우스 휠 : 확대/축소
- 마우스 오른쪽 드래그 : 이동
- 우측 상단 버튼 : 시점 초기화 / 와이어프레임 / 자동회전

포함된 장기: 심장, 뇌, 폐, 간, 신장, 장, 췌장, 안구

교육 목적 전용입니다. 진단·치료에 사용하지 마세요.
모델 출처: Anatomy Atelier (BodyParts3D / Z-Anatomy 기반)
